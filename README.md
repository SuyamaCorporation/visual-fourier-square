# 25 - ビジュアルフーリエ方形波

**ビルド日**: 2026-11-03
**カテゴリ**: visual
**slug**: visual-fourier-square

## 概要
正弦波の奇数次倍音を重ね合わせて方形波に収束する様子をリアルタイムアニメーションで可視化。エピサイクル（回転する円）と合成波形を並べて表示します。

## 機能
- 左パネル: 回転する円（エピサイクル）で各倍音を視覚化
- 右パネル: リアルタイムで書き出される合成波形
- 倍音数スライダー（1〜16、奇数次のみ）でリアルタイム変更
- アニメーション速度スライダー（x1〜x5）
- 再生/一時停止ボタン
- 各倍音を色分け表示（凡例付き）
- 数式表示: f(t) = (4/π) × [sin(ωt)/1 + sin(3ωt)/3 + ...]
- 背景に16次近似の方形波をガイド表示
